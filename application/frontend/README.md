# DevOps Task Manager - React Frontend

React.js Single Page Application (SPA) for the DevOps Task Manager platform.

## Features

- Full CRUD task management
- Priority level tags & filtering
- Real-time Backend and MongoDB Health check status indicator
- User profile & DevSecOps pipeline telemetry summary

## Environment Variables

- `REACT_APP_API_URL` (Default: `http://localhost:5000`)

## Local Development

```bash
npm install
npm start
```
